# Phase 1 — DARE-Bench Agent Reliability Study

First public release of the independent study *Beyond Average Score: Repeatability of LLM Data-Science Agents on DARE-Bench*.

## Included

- Frozen 24-task Classification-IF and Regression-IF subset.
- 5 repetitions under 3-turn and 5-turn budgets, totaling 240 immutable run identities.
- Independently rescored run table, raw-run integrity audit, reliability statistics, task-bootstrap confidence intervals, failure analysis, and publication figures.
- Deterministic documentation and figure generators with drift-detection tests.

## Headline result

Official exact-match success increased from 34.2% to 50.0%; flaky-task rate and pairwise disagreement also increased. The README reports the complete result with descriptive task-bootstrap intervals and limitations.

# v1.0.1 — Reproducibility fixes and a plain-language README

No result changed. Every number is the same as in `v1.0.0-phase1`.

## What changed

- **Hashes now verify on every system.** The published SHA-256 hashes were taken on Windows, and Git checked those files out with different line endings on Linux and macOS, so some checks and tests failed there. [`.gitattributes`](../../.gitattributes) now keeps each hashed file's original line endings.
- **The frozen-code tag is public.** `phase1-execution-freeze-v2` (commit `94d1fe4`) is now on GitHub.
- **Setup works on Linux.** The bootstrap scripts clone DARE-Bench to `vendor/DARE-Bench`, the path the code expects, and install the agent packages too.
- **A new README** that explains the study in plain language. The numbers are still generated from `results/derived/` and checked by tests.
- **Automatic checks.** GitHub recomputes the statistics and runs the tests on Linux and Windows after every change.
- **Tests run on a fresh clone.** Tests that need the DARE-Bench download now skip with a clear reason instead of crashing.
- **Small cleanups.** Removed an unused script, and added a note explaining the `TBD` model fields in the original plan.
